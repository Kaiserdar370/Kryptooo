# kryptooo site

Static, dependency-free site (HTML, CSS, JS). 19 pages generated by `build.py`.

## Before you publish
1. Open `build.py` and edit CONFIG: domain, company name, email addresses, postal address, `UPDATED` date.
2. `python3 build.py` regenerates the `public/` folder (sitemap.xml, robots.txt, ads.txt, canonical URLs and structured data all follow CONFIG).
3. Preview: `python3 -m http.server 8080 -d public`
4. Upload the contents of `public/` to any static host (Netlify, Cloudflare Pages, GitHub Pages, S3).

## AdSense
- Leave `ADSENSE_PUB` empty until Google approves the site. With it empty, no ad code loads and no ad slots render.
- After approval, set `ADSENSE_PUB` ("pub-XXXXXXXXXXXXXXXX") and `ADSENSE_SLOT`, rebuild, redeploy. ads.txt is written for you.
- Ads load only after a visitor clicks "Accept all". For EEA/UK/Swiss traffic use a Google-certified CMP (e.g. Funding Choices).
- Ads appear only on the home page, the Learn hub and articles, never on legal, contact or 404 pages.

## Things only you can do
- Real data: market data is simulated. Connect a licensed feed and update the Disclaimer, About and Editorial pages accordingly.
- Have a lawyer review the Privacy Policy, Terms and Cookie Policy for your jurisdiction.
- Add real original content over time; AdSense reviews value to visitors, not page count.
